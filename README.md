# Chatarrerianew / Chatarrero24h

Proyecto Next.js optimizado para SEO local, GEO/AEO/LLMO y captación por llamada/WhatsApp para Chatarrero24h.

## Stack

- Next.js App Router
- TypeScript
- SEO técnico con sitemap y robots dinámicos
- Schema JSON-LD: LocalBusiness, Service, FAQPage, BreadcrumbList, WebSite
- Landings SEO por servicio y localidad
- Imágenes SVG optimizadas en `public/images`

## Scripts

```bash
npm install
npm run dev
npm run build
npm run start
```

## Despliegue recomendado

Importar este repositorio en Vercel como proyecto Next.js:

- Repository: `chiriflydraven/chatarrerianew`
- Framework: Next.js
- Root directory: `./`
- Build command: `npm run build`
- Install command: `npm install`

No conectar `chatarrero24h.com` hasta validar la preview.
